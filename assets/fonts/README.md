# Fonts

`Archivo-ExtraBold.ttf` is Archivo (weight 800) by Omnibus-Type, licensed under the
SIL Open Font License 1.1. It was downloaded from Google Fonts
(fonts.gstatic.com, Archivo v25) on 2026-11-01.

It is used only by `src/app/opengraph-image.tsx`: `next/og` needs a TTF/OTF/WOFF
file, while the site itself loads Archivo through `next/font` (woff2).
